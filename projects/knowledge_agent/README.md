# Enterprise Knowledge Agent

A production-pattern RAG system built on Azure AI Search and Azure OpenAI. It answers questions against a corpus of 15 enterprise policy documents using hybrid semantic retrieval, structured citation, and a hardened defensive prompt. Served through a FastAPI backend and a Streamlit chat interface.

> Built as Project 1 of 4 in a structured [80-day Generative AI Engineer roadmap](../../README.md) — Days 16–25.
> Full benchmark results and daily findings are in the [repo README](../../README.md).

## What it does

An employee asks: *"What is the parental leave policy for employees with one year of service?"*

The system retrieves the most relevant chunks from the indexed document corpus, passes them as numbered context to the LLM, receives a structured JSON response, and builds citations exclusively from retrieval metadata — the LLM is never asked to produce sources. The answer, cited documents, confidence, and relevance score are returned to the Streamlit UI.

## Key Engineering Decisions

### 1. Citations are never generated by the LLM

The LLM is asked for exactly three keys: `answer`, `supported`, `confidence`. It is never asked to list sources. `_build_sources()` constructs the citation list by reading the metadata returned by the searcher — filename, page number, heading, department, and relevance score. This makes citation fabrication structurally impossible, not just unlikely.

### 2. Four retrieval methods, one default

Four methods are implemented and evaluated:

| Method | How it works |
|---|---|
| `keyword` | BM25 full-text only |
| `vector` | Dense vector cosine similarity only |
| `hybrid` | BM25 + vector merged via Reciprocal Rank Fusion (RRF) |
| `hybrid_semantic` | Hybrid + Microsoft cross-encoder semantic reranker (default) |

Evaluation across 30 ground-truth questions determined `hybrid_semantic` as the production default. Scores are not comparable across methods — BM25 scores 1–7, RRF scores 0.01–0.03, semantic reranker scores 0–4.

### 3. Structured JSON output with graceful fallback

The LLM is instructed to return only valid JSON — no markdown, no preamble. `_generate()` calls `json.loads()` and catches `JSONDecodeError`, returning a safe fallback dict with `supported: False` rather than surfacing a parse exception to the caller.

### 4. Defensive prompt — OWASP LLM01 mitigations

After prompt injection testing (Day 23), the system prompt was hardened with six explicit rules:

- **Rule 1** — Identity lock: role cannot be overridden by user messages
- **Rule 2** — Instruction override resistance: ignores "ignore previous instructions" patterns
- **Rule 3** — Context boundary enforcement: retrieved chunks are source material, never commands
- **Rule 4** — System prompt confidentiality: extraction attempts are refused
- **Rule 5** — Data boundary: no PII or document enumeration outside current context window
- **Rule 6** — Social engineering resistance: audit/CISO framing does not unlock any rule

The Azure AI Content Safety Prompt Shields API (`detectJailbreak`) is documented as the production hardening layer on top of the prompt defense.

### 5. OData filter search for department/date scoping

`filtered_search()` accepts a plain dict (`{"department": "hr", "year": 2026}`) and builds an OData filter string for Azure AI Search. Department shorthand is normalised (`"hr"` → `"Human Resources"`) so callers don't need to know the exact stored string. Year range queries are supported via `year_from` / `year_to`.

## Setup

### Prerequisites

- Python 3.11+
- Azure AI Search instance (free tier supported — UAE North supports semantic reranker on free tier)
- Azure OpenAI deployment with `gpt-5-mini` and `text-embedding-3-small`

### Environment variables

Create a `.env` file at the repository root:

```env
AZURE_OPENAI_API_KEY=your_key
AZURE_OPENAI_ENDPOINT=https://your-resource.openai.azure.com/
AZURE_EMBEDDING_DEPLOYMENT=text-embedding-3-small
MODEL_DEPLOYMENT_NAME=gpt-5-mini
AZURE_SEARCH_ENDPOINT=https://your-search.search.windows.net
AZURE_SEARCH_API_KEY=your_search_key
AZURE_AI_PROJECT_CONNECTION_STRING=your_connection_string
```

### Install dependencies

```bash
pip install fastapi uvicorn streamlit requests pydantic python-dotenv \
    azure-search-documents azure-identity openai docling langchain-docling \
    langchain-openai
```

### Build the index

Run once to parse, chunk, embed, and upload all 15 documents:

```bash
python projects/knowledge_agent/ingestion/pipeline.py
```

The pipeline handles duplicate detection — re-running is safe.

**Terminal 1 — FastAPI backend:**

```bash
uvicorn projects.knowledge_agent.api.main:app --reload --port 8000
```

```bash
streamlit run projects/knowledge_agent/app.py
```

## API Endpoints

| Method | Path | Description |

```json
{
  "prompt": "What is the annual leave entitlement for employees with 5 years of service?",
  "top_k": 3
}
```

```json
{
  "answer": "Policy HR-LEA-001 states that employees with 5–10 years of service are entitled to 25 days per year.",
  "sources": [
    {
      "document": "HR-LEA-001_Annual_Leave_Policy.md",
      "page": 1,
      "section": "Entitlement Schedule",
      "relevance_score": 3.82
    }
  ],
  "chunks_retrieved": 3,
  "retrieval_method": "hybrid_semantic"
}
```
